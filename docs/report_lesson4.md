# Отчёт по занятию 4. Состояние агента умного дома на базовых структурах данных

**Направление:** Умный дом
**Проект:** ООП-прототип агента умного дома
**Дата:** 21.10.2026

## Цель работы
Описать состояние агента через переменные, словари и списки, обработать события датчиков циклом и получить решения по климату и безопасности.

## Входные данные
События из `data/smart_home_events_raw.csv`: температура, освещённость, движение, состояние двери и режим контроллера. Всего 20 событий.

Пороги агента заданы словарём `THRESHOLDS`:
- температура: `hot = 25.0`, `cold = 18.0`;
- свет: `dark = 50`, `bright = 300`;
- безопасность: дверь `open` при режиме `away`.

## Структуры данных
- `THRESHOLDS` — словарь порогов реакции агента;
- `events` — список словарей с событиями датчиков и вычисленным `light_state`;
- `decisions` — список словарей с решениями по каждому событию.

Классы в этой работе не используются.

## Что сделано
- Создан файл `src/home_state.py`.
- События загружены из существующего CSV проекта.
- Для каждого события циклом определены `climate_action` и `security_action`.
- Результаты собраны в список `decisions` и выведены на экран.
- Результат проверен через `assert`.

## Результат
Команда `python src/home_state.py` выводит 20 решений, например:

```text
{'room': 'kitchen', 'climate_action': 'keep_climate', 'security_action': 'security_ok'}
{'room': 'bedroom', 'climate_action': 'keep_climate', 'security_action': 'send_door_warning'}
{'room': 'kitchen', 'climate_action': 'turn_on_cooling', 'security_action': 'security_ok'}
{'room': 'living_room', 'climate_action': 'turn_on_heating', 'security_action': 'security_ok'}
Проверка базовых структур пройдена
```

## Проверка

```text
python -m pytest tests/ -v
```
