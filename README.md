# ООП-прототип агента умного дома — старт

Направление: **Умный дом** (на весь модуль).

## Структура
```
data/  — smart_home_events_raw.csv (время, комната, температура, свет, движение, дверь, режим)
src/   — home_state.py (структуры), home_rules.py (правила), agent.py (заготовка ООП)
tests/ — тесты
docs/  — passport.md (паспорт), backlog.md (бэклог)
```

## Быстрый старт
1. Посмотреть паспорт: `docs/passport.md`
2. Посмотреть данные: `data/smart_home_events_raw.csv`
3. Посмотреть бэклог: `docs/backlog.md`
4. Запустить проверку данных и правил агента:
```
python -m pytest tests/ -v
```
5. Посмотреть работу функций правил:
```
python src/home_rules.py
```
6. Посмотреть базовые структуры состояния агента (занятие 4):
```
python src/home_state.py
```

## Первый коммит
`Старт проекта: паспорт, структура папок и smart_home_events_raw.csv`
